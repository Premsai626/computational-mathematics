Jacobi Iteration Simultaneous Updates

Decomposes coefficient matrix $A$ into diagonal $D$ and remainder $R$. Each variable is computed using solely the values from iteration $k$:

Mathematical Formula
xi(k+1) = (1 / aii) × [bi − Σj≠i aij xj(k)]

• Trivially parallelizable across compute threads
• Requires diagonal dominance (|aii| > Σ|aij|)

Gauss-Seidel Method In-Place Updates

Accelerates convergence by substituting newly computed values immediately within the same iteration pass:

Mathematical Formula
xi(k+1) = (1 / aii) × [bi − Σj<i aij xj(k+1) − Σj>i aij xj(k)]

• Typically converges in ~50% fewer iterations
• Lower spectral radius ρ(T) yields faster residual decay

Educational Project Model: ChemicalMix is built for the college Python Programming and Visual Computing (PPVC) curriculum. The algorithms assume ideal volume additivity and compatible solutions. Not intended as a certified chemical safety assessment.
