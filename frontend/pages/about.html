Project Overview

ChemicalMix is a web-based scientific computing platform engineered for the Python Programming and Visual Computing (PPVC) academic course. It illustrates the real-world application of numerical linear algebra by resolving chemical solution proportion mixtures using iterative algorithms.

Problem Statement

Given multiple chemical stock solutions of known concentrations ($C_1, C_2, \dots$), calculate the exact volumetric proportions required to produce a final mixture with a specified target concentration $C_t$ and total volume $V$, modeled as a simultaneous linear system $Ax = b$.

Core Objectives

✓
Apply computational linear algebra to chemical formulation constraints.
✓
Implement rigorous Jacobi and Gauss-Seidel iterative methods from scratch.
✓
Decouple computational Python Flask backend from client visualization.
✓
Visualize rate of convergence and residual decay via dynamic Chart.js plots.
