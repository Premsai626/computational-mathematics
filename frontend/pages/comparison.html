Jacobi Iteration

Simultaneous Decomposition

Decomposes $A = D + R$. All unknowns $x_i^{(k+1)}$ are computed concurrently using only values from the previous iteration $k$.

Algorithm Formula
xi(k+1) = (1/aii) × (bi − Σj≠i aijxj(k))

Gauss-Seidel Iteration

Sequential In-Place

Decomposes $A = (D - L) - U$. As soon as $x_i^{(k+1)}$ is determined, it is immediately substituted into calculations for $x_{i+1}$.

Algorithm Formula
xi(k+1) = (1/aii) × (bi − Σj<i aijxj(k+1) − Σj>i aijxj(k))
